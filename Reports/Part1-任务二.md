# Part1 任务二：怎么优化你的模型？

## 目标函数

1. L1、L2 范数的定义是什么？在几何意义上表示什么意思？请你用简单的例子进行解释。

    L1 就是把各个分量的绝对值直接加起来，L2 是把各个分量平方之后加起来再开个根号，这两个其实都是在量"差距有多大"，只是量的方式不一样，顺便记一笔，L2 和 MSE 不是一回事，MSE 是平方和除以元素的个数，没有再开根号，我一开始以为这俩就是一个东西

    放到几何上看，把每个分量当成一个坐标轴，L1 只能顺着坐标轴横着竖着走，走的总路程就是 L1，这个一般叫曼哈顿距离，就像出租车在街区里只能拐着弯走横竖两条线，L2 是两点之间的直线距离，勾股定理算出来的那个，也就是欧氏距离，因为绕路总不会比直着走短，所以 L1 永远不会比 L2 小

    举个例子，平面上 A(0,0) 到 B(3,4)

    ```text
    L1 = |3-0| + |4-0| = 3 + 4 = 7
    L2 = √(3² + 4²)    = √25    = 5
    ```

    放到图上是一个道理，一张 128×128 的彩色图有 3×128×128 = 49152 个数值，可以看成 49152 维空间里的一个点，L1 就是把这 49152 个差值绝对值加起来

2. 在使用 L1、L2 损失函数时，计算过程是怎样的？它是如何从两张图片（模型输出和真实无雨图）得到一个最终的损失值的？

    一张 128×128 的彩色图在内存里是个形状 `(3, 128, 128)` 的张量，一共 3 × 128 × 128 = 49152 个数，模型输出和真实无雨图这么一逐位相减，就得到 49152 个差值，然后

    ```text
    L1 损失（MAE）：
        每个差值取绝对值  →  全部加起来  →  除以 49152 求平均

    L2 损失（代码里实际用的是 nn.MSELoss）：
        每个差值平方      →  全部加起来  →  除以 49152 求平均
    ```

    这里得说清楚一件事，L2 范数和 MSE 差的不是一个根号。L2 范数是把平方和直接开根号、不除以元素个数；MSE 是除以个数、不开根号

```text
L2 范数 = √(Σd²)
MSE     = Σd² / N            N = 49152
L2 范数 = √(N · MSE)         ← 不是 √(MSE)
```

`√(MSE)` 单独有个名字，叫 RMSE（均方根误差），跟 L2 范数不是一回事。代码里 `--loss l2` 走的是 `nn.MSELoss()`，所以这次训练真正最小化的是 MSE，不是 L2 范数，这个区别挺容易被问到的

    这里有个地方我一开始搞错了，这三步是把全部 49152 个数放一起做的，三个通道和所有的空间位置混在一起算平均，不是分通道各自算完再平均

    实际训练的时候一次喂 8 张图进去（`batch_size = 8`），所以最后这个损失是对 8 × 49152 = 393216 个数一起求的平均

## 评估指标

### PSNR

题干给的定义里，对数上面那个分子是"图像点颜色的最大值"的平方，8 位表示的时候就是 255，下面那个分母是两张图像在所有像素上的均方误差 MSE

写成一个式子大概长这样

```text
PSNR = 10 × log₁₀( MAX² / MSE )
```

MAX 是像素能取到的最大值，归一化到 [0,1] 的时候是 1，用 8 位整数表示的时候是 255，分母的 MSE 越小，log 里面那个值就越大，PSNR 就越高，所以这个数越大代表两张图越接近

它对异常值敏感是因为 MSE 里面有平方，一个差 100 的像素贡献是 10000，一个差 10 的像素贡献只有 100，前者是后者的 100 倍，差一点点就差出去好多

比如说 100 个像素里面 99 个一模一样，只有 1 个差 100

```text
MSE  = (99×0² + 1×100²) / 100 = 100
PSNR = 10 × log₁₀(255² / 100) ≈ 28.1 dB
```

要是那 1 个像素只差 10 呢，MSE = 1，PSNR ≈ 48.1 dB，就差了这一个像素，分数直接掉下去 20 dB，所以少数几个坏点就能把 PSNR 拉得很低，而人眼可能压根没注意到那个点，这就是 PSNR 不太行的地方，它只看逐个像素的数值差，不管人眼看着舒不舒服

### SSIM

1. SSIM 的数值范围是多少

    理论上是 [-1, 1]，1 表示两张图完全一样，实际用的时候基本都落在 0 到 1 之间，-1 是两张图完全反相，平时基本碰不到

2. SSIM 对图片的考虑主要从哪几个角度

    三个，亮度、对比度、结构，分别对应两张图的平均亮度是不是接近，明暗变化的幅度是不是接近，还有像素之间的空间关系是不是一致

3. 不同于 PSNR，SSIM 每一次的评估对象是什么

    PSNR 是逐个像素在比，对应位置的像素值相减，再对所有像素求平均

    SSIM 是在一个局部的小窗口里先算出一个值，然后窗口滑过去，把所有窗口的结果再取平均

    所以两个比的东西根本不是一个量级，PSNR 比的是像素，SSIM 比的是窗口

    这个差别挺要命的，PSNR 逐个像素对齐着比有个毛病，把一张图整体平移几个像素，人眼看着几乎没变，PSNR 却会掉得很惨，因为每个像素都对不上了，SSIM 看的是窗口里面的亮度对比度结构，对这种变化宽容得多，也更接近人眼判断"像不像"的方式
