# Part2 第二部分 任务二：向量、内积与余弦相似度

这三问是后面写对比损失的地基。我高中的向量忘得差不多了，线代也没正经学过，是看 3b1b 的《线性代数的本质》第一集补的，下面按三问的顺序记。

## 1. 向量是什么，什么是维度

向量在计算机里就是一组有顺序的数字，比如 `(3, 5, 1.2)`。这个"有顺序"很关键，同样的三个数换个顺序就是另一个向量了。

但它还有另一种看法，就是中学讲的那个：从原点出发、指向空间里某一点的一个箭头。同一个向量，既可以当成一组数来算，也可以当成空间里的一个箭头来看。这两种看法在后面算内积的时候会碰到一起。

```text
一套房子：面积 89 平方米，房龄 5 年，到地铁 1.2 公里
       →  (89, 5, 1.2)

一张 2×2 的灰度图 [[10, 20], [30, 40]]
       →  (10, 20, 30, 40)
```

维度就是这组数里面有几个数。上面房子那个是 3 维，图片那个是 4 维。

有一个地方我一开始没意识到，向量本身并不知道自己代表什么。`(89, 5, 1.2)` 之所以能说成"面积、房龄、距离"，是我人为把三个位置约定成这三件事的，换一套约定它就能表示别的东西。这一点在后面用处很大：一张图压成一条向量之后，那条向量里每个数是什么意思我们其实不知道，但照样能拿它来比相似度。

## 2. 向量内积的两种表示方法

内积有两种写法，算出来的结果一定一样，只是入手的地方不同。

第一种是坐标式，把两个向量的对应分量一位一位乘起来，再把所有乘积加起来：

```text
a = (a1, a2, ..., an)
b = (b1, b2, ..., bn)

a · b = a1b1 + a2b2 + ... + anbn

例：(1, 2, 3) · (4, 5, 6)
   = 1×4 + 2×5 + 3×6
   = 4 + 10 + 18
   = 32
```

第二种是几何式，两个向量的长度相乘，再乘上它们夹角的余弦：

```text
a · b = |a| · |b| · cosθ

|a|、|b| 是两个向量的长度
θ       是两个箭头之间的夹角
```

这两种写法是同一个东西，可以用余弦定理推出来。a、b 和它们的差 a-b 三条边构成一个三角形，a 和 b 的夹角就是 θ：

```text
余弦定理：  |a-b|² = |a|² + |b|² - 2|a||b|cosθ

坐标展开：  |a-b|² = (a1-b1)² + (a2-b2)²
                  = (a1² + a2²) + (b1² + b2²) - 2(a1b1 + a2b2)
                  = |a|² + |b|² - 2(a·b)

两式对照，右边后两项必须相等：

    -2|a||b|cosθ = -2(a·b)

两边同除 -2：

    a · b = |a||b|cosθ
```

所以它跟线性代数的关系很直接：坐标式是纯代数运算，只碰数字；几何式是纯几何量，只碰长度和角度。内积这个定义把两边接上了，同一件事可以换着语言说，算的时候用坐标，想的时候用箭头。

## 3. 内积的意义，余弦相似度

内积最直观的意思是衡量两个向量"对不对得齐"：

```text
同向     a · b = |a| |b|      最大
垂直     a · b = 0
反向     a · b = -|a| |b|     最小
```

垂直于对方的那部分分量对结果没有贡献，所以内积是 0；方向一致时所有分量都往一个方向使力，所以最大。

但这里有个坑：内积的数值同时受长度影响。`a` 和 `2a` 方向完全一样，内积却整整翻了一倍。所以看到内积大，分不清是方向真的接近，还是单纯因为两个向量都很长。

想只看方向，就把长度除掉：

```text
                a · b
cosθ  =  ─────────────────────
            |a| · |b|
```

除掉之后剩下的这个就叫余弦相似度，范围是 -1 到 1：

```text
 1   完全同向
 0   垂直，方向上毫无关系
-1   完全反向
```

它只看夹角，不管长短。两条向量长度差十倍，只要方向一样，余弦相似度仍然是 1。

这个量在后面的任务里直接用得上：把去雨结果和无雨真值分别压成一条向量，两条向量的余弦相似度高，就说明模型在特征层面学到了东西；反过来，去雨结果和有雨输入的余弦相似度应该低，因为雨被去掉之后，特征方向本来就该跟原来不一样了。
